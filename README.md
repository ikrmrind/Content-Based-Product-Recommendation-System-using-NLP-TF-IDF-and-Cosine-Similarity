## ✨ Features

- 🔍 **Live Search** — Instantly search across 4,090 products as you type
- 🏷️ **Category Filters** — Narrow results by product category
- 🖼️ **Product Gallery** — Real product images rendered in a clean visual grid

## 🚀 Installation & Setup

**1. Clone the repository**

```bash
git https://github.com/ikrmrind/Content-Based-Product-Recommendation-System-using-NLP-TF-IDF-and-Cosine-Similarity.git
cd Content-Based-Product-Recommendation-System-using-NLP-TF-IDF-and-Cosine-Similarity
```

**2. Create a virtual environment (recommended)**

```bash
python -m venv venv
source venv/bin/activate      # macOS / Linux
venv\Scripts\activate         # Windows
```

**3. Install dependencies**

```bash
pip install -r requirements.txt
```

**4. Add your model files**

Ensure the following exported files are in the root directory alongside `app.py`:

- `tfidf_matrix.pkl` — Pre-computed TF-IDF feature matrix
- `indices.pkl` — Product-name → index mapping
- `products.pkl` — Product metadata dataframe

> 💡 These files are generated by running the training notebook. You can train the model yourself or download the pre-built pickles from the releases page.

**5. Run the application**

```bash
python app.py
```

The app will be available at **http://127.0.0.1:5000/**

## 🧠 How It Works

ShopSense uses a **content-based filtering** algorithm powered by NLP:

1. **Text Aggregation** — Product names, categories, descriptions, and tags for **4,090 products** are combined into a single text field.
2. **NLP Preprocessing** — The text is lowercased, stopwords are removed, and words are lemmatized using NLTK.
3. **TF-IDF Vectorization** — Text is converted into a **TF-IDF matrix** using unigrams + bigrams with **10,000 features**.
4. **Cosine Similarity** — When a product is selected, its TF-IDF vector is compared against all others to compute cosine similarity scores.
5. **Ranking** — The top **12 most similar products** are returned, each with a **% match score** displayed in the UI.
